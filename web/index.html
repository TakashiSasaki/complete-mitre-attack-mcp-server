MITRE ATT&CK MCP Server

MITRE ATT&CK（Enterprise / Mobile / ICS）の戦術・テクニック・脅威グループ・ソフトウェア情報を提供する Streamable HTTP MCP サーバーです（imouiche/complete-mitre-attack-mcp-server ベース）。

エンドポイント

  • MCP (Streamable HTTP): https://mitre-attack.moukaeritai.work/mcp
  • ヘルスチェック: /healthz

※ /mcp および /healthz へのアクセスは許可されたクライアント IP / Google Cloud MCP IP 帯域のみに制限されています。

主な機能

  • 横断検索・フィルタ: 戦術（Tactic）、プラットフォーム、脅威グループ（APT）、マルウェア・正規ツール（Software）からの TTP 逆引き
  • 全ドメイン対応: Enterprise / Mobile / ICS（制御システム・アセット）を網羅する 65 以上の MCP ツール
  • 緩和策・検知データソース: 各テクニックに対する緩和策（Mitigations）と検知用データコンポーネントの参照
  • ATT&CK Navigator 連携: 検証済み／対象テクニックの Navigator レイヤー JSON 生成
  • ローカル STIX キャッシュ: 公式 STIX 2.1 バンドルをホスト内へローカル保存して高速検索
